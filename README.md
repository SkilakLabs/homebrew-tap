# Skilak Labs Homebrew tap

Public Homebrew tap for reviewed Skilak Labs products.

When a formula is published:

```sh
brew tap skilaklabs/tap
brew install smesh
```

Formulae in this repository point only to published assets in
`SkilakLabs/releases`. Repository visibility does not publish a draft release;
a formula is added only after its matching release passes the documented
checksum, provenance, signing, and installation gates.

| Formula | Product |
|---|---|
| `smesh` | SkilakMesh - self-hosted DLP gateway for outbound AI traffic |
