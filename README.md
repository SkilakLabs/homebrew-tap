# Skilak Labs Homebrew tap

Private tap for Skilak Labs products.

```sh
brew tap skilaklabs/tap
brew install smesh
```

Tapping requires access to this repository. Formulae here point at
authenticated private release assets, so both the tap and the download
are access-controlled.

| Formula | Product |
|---|---|
| `smesh` | SkilakMesh — self-hosted DLP gateway for outbound AI traffic |
